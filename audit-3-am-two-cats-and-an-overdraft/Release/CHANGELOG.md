# Changelog
All notable changes to the *3 AM, Two Cats & An Overdraft* release will be documented in this file.

## [1.2.0] - 2026-09-14
### Added
- Comprehensive Multidisciplinary Audit Suite in `/audit-3-am-two-cats-and-an-overdraft/`.
- Automated test runner `tests/validate_album.test.js`.
- GitHub Actions CI workflow for pull request and push verification.
- Schema.org `MusicAlbum` JSON-LD structured data and `sitemap.xml` for rich Google search indexing.
- Color-coded track status badges (`MASTER` vs `STUDIO`).
- Resilient video playback fallback for tracks in studio synthesis.

### Fixed
- Critical JavaScript `SyntaxError: Invalid or unexpected token` in inline `lyricsData`.
- Unicode character encoding corruption in `README.md` and `LINER_NOTES.md`.

## [1.0.0] - 2026-09-14
### Initial Release
- Studio Deluxe Edition featuring 16 original tracks, 1080p MP4 music videos, real-time Web Audio API visualizer, and full interactive lyrics suite.
