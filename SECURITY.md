# Security Policy

## Supported Versions
Only the latest commit on the `main` branch deployed to GitHub Pages is supported.

## Reporting a Vulnerability
If you discover a security issue or vulnerability in the interactive player or repository assets, please do not open a public issue. Instead, report it privately to:
- **Project Maintainer:** David Linacre
- **Response Commitment:** Initial review within 48 hours, security patches deployed within 7 business days.
